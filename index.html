    Themes

    Two ways to Theme

    Editing these directly in ri.css
    Or editing these variable in your style sheet and editing them 
    :root {
	--ri-border-size: 2px;
	--ri-border-radius: 0.5rem;
	--ri-color: #22b;
	--ri-spacing: 1rem;
}
    Editing themes per element
    By using these attributes and classes
    Via Attribute 
    <tag data-ri-color="HTML Color Name"></tag>

    <tag data-ri-hue="Number from 0 to 360"></tag>
    Via Classes
    ri-theme-dark ri-theme-light
    ri-font-code ri-font-sans ri-font-serif
    ri-rounded-none ri-rounded-min ri-rounded-max
    ri-width-full

    Attributes allows you to dynamically theme your elements to your liking, while keeping the css lightweight.
    Mix and Match to get exactly what you want.
